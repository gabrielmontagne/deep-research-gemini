= deep-research-gemini

Thin CLI and MCP wrapper for Gemini Deep Research Agent.

== Requirements

* `uv` (for installation)
* `GEMINI_API_KEY` environment variable

== Installation

From the repository directory:

[source,bash]
----
cd /path/to/deep-research-gemini
uv tool install .
----

To update after making changes:

[source,bash]
----
uv cache clean --force
uv tool uninstall deep-research-gemini
uv tool install .
----

== MCP Configuration

Add to your `opencode.jsonc` (or equivalent):

[source,jsonc]
----
"mcp": {
  "deep-research": {
    "type": "local",
    "enabled": true,
    "command": ["deep-research-gemini", "--mcp", "--report-dir", "./transient/"]
  }
}
----

Optional: Add `--format-instructions` to append formatting rules to every query:

[source,jsonc]
----
"command": [
  "deep-research-gemini",
  "--mcp",
  "--report-dir", "./transient/",
  "--format-instructions", "./format-instructions.txt"
]
----

== CLI filter mode

Pipe a query on stdin and print the final report text to stdout:

[source,bash]
----
deep-research-gemini < query.md > report.md
----

This waits in the foreground. The successful report body is written to stdout.

== MCP Tool

`deep_research(query, report_name)`

* `query` - The research question or task
* `report_name` - Slug for the output filename (e.g., `ev-battery-landscape`)

Returns path to generated report: `Report generated: ./transient/20251212143022-ev-battery-landscape.txt`

Research typically takes several minutes.
